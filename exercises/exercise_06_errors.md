# Exercise 6: Deliberate Errors

Practice reading error messages. **These errors are intentional.**

Run each command, read the message, then recover.

## Error 1: Wrong folder name

```bash
ls wrong_folder
```

What does the message say? Recover with `pwd` and `ls`.

## Error 2: Typo in command name

```bash
grepp macroglobulin data/reference/proteins.fa
```

Fix the typo and run the correct command.

## Error 3: Unclosed quote

```bash
grep "DDX11L1 data/annotation/pseudogenes_chr1.gff
```

The terminal waits. Press **Ctrl + C** to stop.

## Reflection

For each error, write one sentence: what went wrong?
