# Exercise 2: Navigation Treasure Hunt

Make sure you are in the workshop folder root (run `pwd`).

## Tasks

1. Print your current location
2. List the files in the current folder
3. Go into `data/`
4. Go into `raw/`
5. List the FASTQ files
6. Go back to the main workshop folder
7. Go into `data/metadata/`
8. Confirm that `samples.tsv` is there

## Optional challenge

From the main folder, list files inside `data/raw/` **without** moving there.

## Stuck?

```bash
pwd    # where am I?
ls     # what is here?
cd ..  # go up one level
```
